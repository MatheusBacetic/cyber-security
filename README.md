# Cyber Security Labs

Repositório dedicado aos meus estudos e projetos práticos em Cyber Security, Linux, Redes e Segurança Web.

O objetivo deste repositório é documentar minha evolução técnica através da construção de laboratórios, desafios, testes controlados e projetos voltados para segurança ofensiva e defensiva.

---

# Objetivos

* Desenvolver conhecimento prático em Cyber Security.
* Aprender Linux e administração de sistemas.
* Aprofundar conhecimentos em Redes de Computadores.
* Estudar Segurança Web.
* Construir projetos documentáveis para portfólio profissional.
* Aplicar conceitos de segurança em ambientes controlados.

# Metodologia

Todos os projetos seguem a mesma abordagem:

1. Estudo da teoria.
2. Implementação prática.
3. Testes controlados.
4. Validação dos resultados.
5. Documentação do aprendizado.
6. Registro de dificuldades e soluções.

O foco é compreender os conceitos em profundidade e não apenas executar comandos.
