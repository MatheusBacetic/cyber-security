# Firewall nftables

## Table

inet firewall

## Chains

### input

Controla o tráfego destinado ao servidor.

### output

Controla o tráfego gerado pelo servidor.

### forward

Bloqueia tráfego roteado.

### whitelist

Armazena regras de acesso autorizadas.

### logging

Registra pacotes bloqueados.

### diagnostics

Reservada para testes e troubleshooting.
