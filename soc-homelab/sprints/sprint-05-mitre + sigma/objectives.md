# Sprint 5 Objectives

## Primary Objective

Develop portable Sigma detection rules based on Windows Sysmon telemetry and validate the detections using Wazuh.

## Technical Objectives

- Create Sigma rules in YAML format.
- Validate rules using Sigma CLI.
- Map each detection to MITRE ATT&CK.
- Generate controlled and harmless endpoint telemetry.
- Investigate events in Wazuh archives and dashboards.
- Document expected behavior, false positives and tuning opportunities.
- Maintain detection content in a version-controlled repository.

## Professional Outcome

At the end of this sprint, the SOC Home Lab will contain a documented detection library that demonstrates the complete lifecycle of detection engineering:

1. Detection design.
2. Rule validation.
3. Telemetry generation.
4. SIEM investigation.
5. Tuning.
6. Incident triage documentation.
