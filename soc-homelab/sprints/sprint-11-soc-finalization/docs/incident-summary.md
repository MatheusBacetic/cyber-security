|---|---|
| Objective | Validate command execution visibility on the Windows environment. |

## INC-002 - SSH Password Guessing

| Field | Details |
|---|---|
| Objective | Validate SSH password guessing detection and response on the Wazuh Ubuntu server. |
| Telemetry Source | Ubuntu SSH/auth logs and Wazuh correlation. |
| Rule | `100231`, supported by Active Response base rule `100232` |
| MITRE | `T1110.001` - Password Guessing, `T1021.004` - SSH |
| Result | Repeated SSH authentication failures were correlated and alerted. |
| Response | nftables Active Response temporarily blocked the source IP. Rollback was validated by removing the block. |

## Honeypot SSH Brute Force Detection

| Field | Details |
|---|---|
| Objective | Validate the custom C SSH Honeypot + IDS integration with Wazuh. |
| Telemetry Source | Honeypot `alerts.log` exported to `honeypot-wazuh.jsonl`. |
| Rule | `100250` |
| MITRE | `T1110.001` - Password Guessing, `T1021.004` - SSH |
